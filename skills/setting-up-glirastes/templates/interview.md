# Glirastes setup interview

Ask only unresolved questions and group them by tool family.

For each ambiguous tool establish:

1. Should this capability be available to the assistant?
2. Is it read, create, update, delete, UI, or still unclear?
3. Which side effects and data class apply?
4. Does it require approval?
5. Which server-verified roles may use it?

Then establish:

1. Which local model binding should the planner use?
2. Which local prompt bundle should be bound?
3. Which bounded budget profile applies?

Summarize proposed changes and exceptions before validation and sync.
