# Glirastes developer documentation

Start at **[glirastes.io/docs](https://glirastes.io/docs)** for searchable guides,
copyable examples and release-status labels. Guides marked as preview describe
unreleased changes; check their source version against your installed SDK.

- [Getting started](https://glirastes.io/docs/getting-started)
- [Tools and generation](https://glirastes.io/docs/tools)
- [Approvals](https://glirastes.io/docs/approvals) and [security](https://glirastes.io/docs/security)
- [Chat](https://glirastes.io/docs/chat), [sessions](https://glirastes.io/docs/sessions) and [attachments](https://glirastes.io/docs/attachments)
- [Interactions, navigation and commands](https://glirastes.io/docs/interactions)
- [Deployment](https://glirastes.io/docs/deployment) and [support matrix](https://glirastes.io/docs/support)
- [Chat views](chat-views.md) (optional): the model composes views in the chat from the app's components
- [Local speech recognition](local-stt.md) (experimental): `glirastes/server/stt-local` transcribes recordings in the Node process

The [repository's Markdown guides](https://github.com/chainmatics/glirastes/tree/main/docs)
remain the versioned source. For an exact release, open the corresponding Git tag
or use the published guide's source link.
Agent installation instructions are in [skills/README.md](../skills/README.md).
