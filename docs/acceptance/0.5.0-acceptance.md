# Acceptance record for 0.5.0

This table maps each MVP requirement to its automated evidence and to the step
only a person can take. "Automated" means the evidence runs without a person: in the
release gate (SDK `bun run test`, the Platform CI workflow and the Get It Done gate)
or, for the browser suites (`*.test.mjs`), as a local run with an installed Playwright
(`node --test`, see the header of each file; CI does not run them). It never
covers a live model, a live STT provider or a real user. `tests/acceptance-record.test.ts`
checks that every SDK path named here exists.

| Requirement | Automated evidence | Still needs a person |
| --- | --- | --- |
| FR-1 Agent-led setup | `src/cli/installer-e2e.test.ts`, `tests/skill-scenarios.test.ts`, `tests/pack-install.test.ts` | Flow 1 of the user test, with times; a live coding-agent run |
| FR-2 Tools follow code changes | `tests/tool-sync-next.test.ts`, `tests/tool-sync-next-ui.test.ts`, `tests/tool-sync-react-nest.test.ts`, `tests/tool-sync-react-nest-ui.test.ts`, `tests/tool-sync-vue-fastapi.test.ts`, `tests/tool-sync-vue-fastapi-ui.test.ts` | Flow 3 of the user test |
| FR-3 Routing, search and clarification | `src/runtime/__tests__/tool-discovery-relevance.test.ts`, `src/server/core/__tests__/clarification-tool.test.ts`, `src/contracts/__tests__/clarification.test.ts` | Quality with a live model (outside 0.5.0 gates) |
| FR-4 Shared chat UI | `tests/chat-browser.test.mjs`, `tests/chat-interactions-browser.test.mjs`, `tests/chat-interactions-next.test.ts` | A local Playwright run of the two browser suites; the user test |
| FR-5 STT parity | `tests/voice-press-browser.test.mjs`, `tests/recording-bar-browser.test.mjs` | A local Playwright run of the two browser suites; one session with a real microphone and STT provider |
| FR-6 Simple Platform operation | Platform: `apps/citadel` tests and the CI workflow. Connect and sync end to end against Get It Done is not automated yet (plan P13b) | Flows 2 and 5 of the user test |
| FR-7 Technical transparency | `src/contracts/__tests__/runtime-metric-event.test.ts`, `src/runtime/metrics/sink.test.ts`, `src/runtime/metrics/turn-recorder.test.ts`; Platform: `apps/api/src/modules/runtime-metrics` tests | Flow 4 of the user test; the live OpenRouter cost check |
| FR-8 Reuse and reference migration | `docs/support-matrix.md` with `tests/support-matrix.test.ts`; Get It Done gate on its branch | The merge of the Get It Done branch |
